# Geleceğin Dijital Sağlık Liderleri

Proje aktif olarak **React + Vite + Supabase Serverless + Edge Functions + Google Drive API** mimarisi üzerinde çalışmaktadır.

Eski Django REST API koda ait dosyalar geriye dönük referans amacıyla `legacy_backend/` klasörü altına arşivlenmiştir.

## Teknolojiler

- **Frontend**: React 19, Vite, Tailwind CSS, React Router
- **Backend / Veritabanı**: Supabase DB (PostgreSQL), Supabase Auth, Row Level Security (RLS)
- **Serverless / API**: Supabase Edge Functions (Deno / TypeScript)
- **Depolama**: Google Drive API (Service Account)
